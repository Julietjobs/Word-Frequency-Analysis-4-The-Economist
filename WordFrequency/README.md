# 词频分析结果说明

本文件夹包含词频分析的结果文件。

## 包含内容：

- `word_frequency_all.csv` - 完整的词汇列表及其频率
- `level1(-500).csv` 到 `level6(29-20).csv` - 按频率分级的词汇列表


**注意：** 实际的 CSV 文件是通过运行 `batch_process.py` 生成的，不包含在代码仓库中。你需要使用自己的《经济学人》电子书文件来运行分析（或者直接分析解析成txt文件的原文即可）。

## 统计数据参考：

基于 2016-2025 年《经济学人》杂志：
- 总独立词汇数：约 175,000 个
- 高频词汇（Level 1-2）：约 13,000 个
- 推荐学习词汇（Level 1-4）：约 24,000 个
