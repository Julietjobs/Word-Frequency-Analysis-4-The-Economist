# 📚 The Economist 词频统计工具

> 帮助你通过词频分析，系统掌握《经济学人》词汇，实现无障碍阅读的目标

## 🎯 这个项目是什么？

这是一个专门为英语学习者设计的工具，通过分析2016-2025年《经济学人》杂志的所有文章，统计出最常用的单词，并按频率分级，帮助你**高效地背单词**。

## 📖 为什么要用词频学习？

- **高效**：优先学习高频词，用20%的努力掌握80%的内容
- **实用**：这些都是《经济学人》真实使用的词汇
- **系统**：按频率分级，循序渐进
- **目标明确**：掌握这些词汇，你就能轻松阅读《经济学人》

## 🚀 如何使用？

### 对于学习者（不需要编程知识）

1. 直接下载 `WordFrequency` 文件夹中的词汇表
2. 用Excel或记事本打开CSV文件
3. 按照分级顺序背单词
4. 建议配合背单词App（如不背单词、欧陆词典等）导入使用

### 对于想查看原文的同学

- **`txt` 文件夹**包含了2016-2025年所有期刊的纯文本版本
- 可以直接阅读，或用于其他文本分析

### 对于想自己分析的同学

**第一步：准备环境**
```bash
# 需要安装Python 3.6+
pip install ebooklib beautifulsoup4 lxml mobi
```

**第二步：准备杂志文件**
- 将你的《经济学人》电子书（EPUB或MOBI格式）放入 `TheEconomist` 文件夹
- 按年份分类（如：`TheEconomist/2024/`）

**第三步：运行分析**
```bash
python batch_process.py
```

程序会自动：
1. 转换所有电子书为文本
2. 统计词频
3. 生成词汇表
